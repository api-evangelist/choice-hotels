# Choice Hotels

> Choice Hotels International (NYSE: CHH) is a United States hotel franchisor headquartered in North Bethesda, Maryland, operating 7,575 hotels with 656,825 rooms across 49 states, the District of Columbia and 50 countries and territories as of December 31, 2025. Choice publishes **no public API, no developer portal, and no machine-readable API contract**. Everything below is the public, verifiable surface — plus an honest record of what does not exist.

## API posture

- Public developer portal: **none**. `developer.choicehotels.com` is a hostname pointed at TIBCO Mashery with no provisioned portal — it returns HTTP 404 under a `CN=mashery.com` certificate that does not match the hostname.
- Public API reference: **none**.
- Machine-readable contract: **none**. No OpenAPI, Swagger, WSDL, XSD, GraphQL SDL, AsyncAPI, MCP server, or Postman collection exists on any reachable Choice Hotels property.
- API gateway: **live but unmapped**. `api.choicehotels.com` runs TIBCO Mashery (Boomi Cloud API Management) and answers every probed path with HTTP 596 / `X-Mashery-Error-Code: ERR_596_SERVICE_NOT_FOUND`.
- Access model: **commercial agreement only**. Franchisees reach the systems through a franchise agreement; technology vendors through the SkyTouch `/CONNECT` interface program; distributors through an existing GDS, OTA or bed-bank relationship.

## Named systems (from SEC filings — systems, not published APIs)

- **choiceEDGE** — cloud central reservation / global reservation system that manages all distribution: rate, inventory, availability, shopping, booking and reservations for ChoiceHotels.com, the mobile apps, the GDSs (Sabre, Amadeus), the OTAs (Expedia, Booking.com) and metasearch (Kayak, Tripadvisor). Proprietary; no public contract.
- **choiceADVANTAGE** — proprietary property and yield management system used by the significant majority of Choice hotels. Third-party integration is via the SkyTouch `/CONNECT` certified interface catalog, entry to which is a vendor request form.
- **Choice Privileges** — loyalty program. No public member or points API is documented.

## Brands

## Security and legal

- [Responsible Disclosure / Vulnerability Disclosure Policy](https://www.choicehotels.com/legal/responsible-disclosure): report to `responsibledisclosure@choicehotels.com`; acknowledgement within five business days; safe harbour for good-faith research; **no bug bounty**; social engineering, resource exhaustion, physical testing and denial of service are out of scope
- [Privacy Policy](https://www.choicehotels.com/legal/privacy-policy): includes CCPA disclosures for California residents
- [Terms of Use](https://www.choicehotels.com/legal/terms-of-use)
- No `/.well-known/security.txt` is served on any host, so the disclosure channel is not machine-discoverable
- No trust center, no published certifications (no SOC 2 / ISO 27001 / PCI DSS claim found), no status page

## Notes for agents

There is nothing here to call. Do not construct requests against `api.choicehotels.com` — no public service is mapped to it and its certificate does not match its hostname. Choice-branded room inventory is reachable programmatically only through an intermediary that already holds a commercial relationship with Choice (a GDS, an OTA, or a bed bank), and those are separate providers with their own contracts.
